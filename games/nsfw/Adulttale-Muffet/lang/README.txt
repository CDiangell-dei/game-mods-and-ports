This folder is intended for game localization files.

If you want to add your own localization, you can reach out to us on Twitter or Discord (@ivaskiygood) with a
completed file based on eng.json, so we can include it in the general release.

To create your own localization, copy eng.json and rename it to the desired language
(e.g. jap.json). Then, in support.json, add the filename to the array.
After that, the translation will be available in the game.

When modifying files or adding other localizations, the game does not need to be restarted.

WARNING!!
The game's font does NOT contains all characters
